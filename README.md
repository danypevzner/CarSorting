# Car Sorting App

Приложение, которое умеет хранить машины, сортировать их по разным параметрам, искать, удалять и не терять данные даже после закрытия.  
Это не просто «ещё одна программа» — это полноценный консольный менеджер автомобилей с памятью, выбором алгоритмов и многопоточностью.

---

## Что здесь можно делать?

- **Добавлять машины** — вручную или случайной генерацией.
- **Загружать и сохранять** файлы с машинами (формат `.csv` с разделителем `;`).
- **Сортировать** по модели, мощности или году выпуска.
- **Выбирать алгоритм сортировки** — пузырьковая, вставками или выбором.
- **Искать машины** по модели в многопоточном режиме (да, это быстро).
- **Удалять** одну машину по номеру или все сразу (с подтверждением).
- **Автосохранение** при выходе — программа запоминает последний файл и предлагает загрузить его при следующем запуске.

---

## Почему это удобно?

- **Файл запоминается.** При следующем запуске программа спросит: «Загрузить последний сохранённый файл?» — и если ответить «да», всё подхватится автоматически.
- **Ответы на да/нет работают в обеих раскладках.** Можно вводить `да`, `yes`, `lf`, `нет`, `no`, `ytn` — программа поймёт.
- **Сортировка с выбором** — можно сравнить разные алгоритмы на одном и том же списке.
- **Поиск через несколько потоков** — ускорение работы на больших данных.

---

## Как это устроено внутри?

- `Car` — это `record`, который содержит модель, мощность и год выпуска.  
- `CarCollection` — умная коллекция, умеет сортировать по полям, фильтровать чётные значения и считать вхождения.  
- `CliClient` — консольный интерфейс, который общается с пользователем и управляет данными.  
- `FileUtil` — отвечает за чтение и запись файлов, работает с CSV.  
- `lastFile.txt` — маленький служебный файл, в котором хранится имя последнего сохранённого файла.

## Как запустить?

```bash
git clone https://github.com/danypevzner/CarSorting.git
```
Открыть в IntelliJ IDEA, запустить `App.java` — и появится меню.

**Формат файла:**  
Файлы сохраняются в простом текстовом формате:
```
Model;Power;Year
Tesla;250;2020
BMW;200;2010
```
Разделитель — точка с запятой, чтобы легко открывалось в Excel.
